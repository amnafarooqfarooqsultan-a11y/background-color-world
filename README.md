# Color Your World 

A simple and interactive Background Color Changer project built using HTML, CSS, and JavaScript.

##  Features
- Change the background color with a button click.
- Explore 15 different background colors.
- Automatically return to the first color after the last one.
- Simple and user-friendly design.

##  Technologies Used
- HTML5
- CSS3
- JavaScript

##  Purpose
Created to practice DOM manipulation, event listeners, and CSS class manipulation.
